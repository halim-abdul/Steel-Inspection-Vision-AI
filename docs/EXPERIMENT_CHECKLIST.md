# Experiment Checklist

- Define hypothesis and baseline.
- Freeze train/validation/test split before final evaluation.
- Record seed, data version, commit and hardware.
- Check class and asset leakage.
- Report primary and secondary metrics.
- Include uncertainty or confidence intervals when feasible.
- Measure latency and memory for deployment claims.
- Inspect representative false positives and false negatives.
- Document limitations and domain shift.
